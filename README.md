# techCLA

This is a personal copy of a team project I worked on for CS 3240 at UVA. We built a web app that lets people catalog and lend out technological applicances.

### My Role

I was the Scrum Master. I helped keep the team organized, ran meetings, tracked our progress, and made sure we hit our goals each sprint. I also contributed to feature development and testing.

### Tech Highlights

**Backend:** Django, Python, PostgreSQL  
**Frontend:** Bootstrap  
**Auth & Storage:** Google Login, Amazon S3  
**DevOps:** GitHub Actions, Heroku  
**Project Management:** GitHub Projects

This repo is just an archive of our team project so I can keep a record of my work, since the original classroom repo won’t be available forever.
